# ⚡ ZenvoX AI Pro — Multimodal AI & 10-Step STEM Solve Platform

## Quick Deploy on Render.com (From GitHub)
1. Upload these files to your GitHub repository keeping the exact file paths (`package.json`, `server/index.js`, `public/index.html`, `public/css/style.css`, `public/js/app.js`).
2. Create a **New Web Service** on [Render.com](https://render.com) and connect your GitHub repo.
3. Use these settings:
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. In Render **Environment Variables**, add:
   - `GEMINI_API_KEY` = `your_actual_google_gemini_api_key`
   - `JWT_SECRET` = `any_random_secret_string`
5. Click **Deploy Web Service**.
